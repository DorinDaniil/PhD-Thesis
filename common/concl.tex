В~диссертационной работе\else В~диссертационной работе\fi{} решена задача разработки пространственно-временных методов декодирования сигналов высокой размерности, восстанавливающих внешний стимул в условиях ограниченного объема выборки. Методы последовательно учитывают временную, пространственную и межмодальную структуру сигнала и проверены на данных нейровизуализации.

Основные результаты работы заключаются в следующем.
\begin{enumerate}
    \item Построена линейная авторегрессионная модель прогнозирования сигнала по предъявленному стимулу и на ее основе предложен метод оценки лага сигнала по минимуму ошибки прогноза. В информативной области сигнала ошибка имеет выраженный минимум, согласующийся с независимыми оценками лага, тогда как по полному сигналу минимум не выражен. Этот результат обосновывает явный учет лага и выделение информативной области в последующих методах.
    \item Разработан метод классификации многоканальных временных рядов в условиях ограниченной выборки, в котором объект описывается отдельно с точки зрения каждого класса. Маски активности классов выделяются по кросс-корреляции сигнала со стимулом, а ковариационная матрица отобранных каналов проецируется на касательное пространство в точке риманова среднего. Размерность признаков не зависит от объема выборки. На записях одного источника с восемью категориями стимула метод превосходит нейросетевые модели, а исключение любой из компонент значимо снижает качество.
    \item Доказаны теоретические свойства касательных признаков ковариационных матриц. Невырожденное преобразование каналов не меняет предсказаний логистической регрессии. Двусторонняя оценка искажения расстояний имеет неулучшаемую константу, выраженную через спектральный разброс касательных векторов. Для ошибки выборочной ковариации в геодезической метрике получена оценка концентрации, причем распределение ошибки не зависит от истинной ковариации.
    \item Предложена мультимодальная архитектура реконструкции стимула по двум синхронно регистрируемым сигналам, в которой совместные представления контрастивно выравниваются с предобученными представлениями стимула, а стимул восстанавливается двухстадийной диффузионной генерацией. Объединение модальностей повышает качество реконструкции по сравнению с каждой из них в отдельности, а априорная диффузионная модель необходима для семантической согласованности результата.
    \item Разработан метод восстановления отсутствующих каналов по геометрии расположения сенсоров и его вероятностное обобщение на основе маскированного согласования потоков. Доказано, что при точном векторном поле обобщение восстанавливает условное распределение пропусков. Метод применен к записям с неполным набором сенсоров.
\end{enumerate}

Теоретическая значимость результатов заключается в строгом обосновании широко применяемой конструкции касательных признаков. Получены утверждения с явными константами, связывающими число каналов, длину ряда и ошибку признаков. Практическая значимость состоит в применимости методов к любым многоканальным сигналам высокой размерности. Они позволяют декодировать стимул по записям одного источника объемом в десятки объектов, реконструировать стимул нейросетевой моделью по синхронным записям многих источников и обрабатывать записи с неполным набором каналов. Программные реализации методов опубликованы.

Методы оценки лага и классификации рекомендуется использовать при декодировании внешнего стимула по многоканальным сигналам с малой размеченной выборкой, в частности по записям одного источника, когда объем выборки составляет десятки объектов и нейросетевые модели неприменимы. Мультимодальную архитектуру и метод восстановления каналов рекомендуется использовать при построении общих для многих источников нейросетевых моделей реконструкции по синхронным записям нескольких модальностей, в том числе с неполным набором каналов.

К перспективам дальнейшего развития темы относятся обобщение постановки на большее число модальностей с неизвестными взаимными лагами, включение вероятностного восстановления каналов в контур декодирования, а также перенос методов на мультимодальные временные ряды иной природы.
