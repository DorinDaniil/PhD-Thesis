\ifsynopsis\textbf{В заключении} подведены итоги: в~диссертационной работе\else В~диссертационной работе\fi{} решена задача разработки пространственно-временных методов обработки сигналов высокой размерности для декодирования внешнего воздействия в условиях ограниченного объема выборки. Методы последовательно используют временную, пространственную и межмодальную структуру сигнала и проверены на данных нейровизуализации.

Основные результаты работы заключаются в следующем.
\begin{enumerate}
    \item Построена линейная авторегрессионная модель прогнозирования отклика на внешнее воздействие и на ее основе предложен метод оценки лага отклика по минимуму ошибки восстановления. На данных фМРТ в локализованной области отклика ошибка имеет выраженный минимум около пяти секунд, согласующийся с физиологическими оценками, тогда как по всему объему скана минимум не выражен. Этот результат обосновывает явный учет лага и выделение информативной области в последующих методах.
    \item Разработан метод классификации многоканальных временных рядов в условиях ограниченной выборки: маски активности классов выделяются по кросс-корреляции сигнала со стимулом, а ковариация отобранных каналов проецируется на касательное пространство в точке риманова среднего, так что объект описывается отдельно с точки зрения каждого класса. Размерность признаков не зависит от объема выборки; на записях фМРТ одного пациента с восемью категориями стимулов метод превосходит нейросетевые модели, а исключение любой из компонент значимо снижает качество.
    \item Доказаны теоретические свойства касательных признаков ковариационных матриц: инвариантность к невырожденному преобразованию каналов, не меняющая ответ логистической регрессии; двусторонняя оценка искажения расстояний с неулучшаемой константой, выраженной через спектральный разброс касательных векторов; оценка концентрации ошибки оценки ковариации в геодезической метрике, распределение которой не зависит от истинной ковариации.
    \item Предложена мультимодальная архитектура реконструкции стимула по двум синхронно регистрируемым сигналам с контрастивным выравниванием совместных представлений с пространством CLIP и двухстадийной диффузионной генерацией. На одновременных записях фМРТ и ЭЭГ объединение модальностей повышает качество реконструкции по сравнению с каждой из них в отдельности, а априорная диффузионная модель необходима для семантической согласованности результата.
    \item Разработан метод восстановления отсутствующих каналов многоканального сигнала по геометрии расположения сенсоров и его вероятностное обобщение на основе маскированного согласования потоков; доказано, что при точном векторном поле обобщение восстанавливает условное распределение пропусков. Метод применен к записям ЭЭГ с неполным монтажом.
\end{enumerate}

Теоретическая значимость результатов заключается в строгом обосновании широко применяемой конструкции касательных признаков: получены утверждения с явными константами, связывающими число каналов, длину ряда и ошибку признаков. Практическая значимость состоит в применимости методов к любым многоканальным сигналам высокой размерности и, в частности, в возможности декодирования по записям одного пациента объемом в десятки объектов, в межсубъектной нейросетевой реконструкции стимула по одновременным записям фМРТ и ЭЭГ и в работе с записями с неполным набором каналов; программные реализации методов опубликованы.

Результаты работы рекомендуется использовать при декодировании внешнего воздействия по многоканальным сигналам с малой размеченной выборкой, в частности по записям одного пациента, когда объем выборки измеряется десятками объектов и нейросетевые модели неприменимы, для чего предназначены методы оценки лага и классификации, и при построении межсубъектных нейросетевых моделей реконструкции по синхронным записям нескольких модальностей, в том числе с неполным набором каналов.

К перспективам дальнейшего развития темы относятся обобщение постановки на большее число модальностей с неизвестными взаимными лагами, включение вероятностного восстановления каналов в контур декодирования, а также перенос методов на мультимодальные временные ряды иной природы.
