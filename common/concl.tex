\ifsynopsis\textbf{В заключении} подведены итоги: в~диссертационной работе\else В~диссертационной работе\fi{} решена задача разработки пространственно-временных методов обработки сигналов высокой размерности, обеспечивающих декодирование внешнего воздействия в условиях ограниченного объема выборки. Методы последовательно используют временную, пространственную и межмодальную структуру сигнала и проверены на данных нейровизуализации.

Основные результаты работы заключаются в следующем.
\begin{enumerate}
    \item Построена линейная авторегрессионная модель прогнозирования отклика на внешнее воздействие и на ее основе предложен метод оценки лага отклика по минимуму ошибки восстановления. В локализованной области отклика ошибка имеет выраженный минимум, согласующийся с независимыми оценками лага, тогда как по полному сигналу минимум не выражен. Этот результат обосновывает явный учет лага и выделение информативной области в последующих методах.
    \item Разработан метод классификации многоканальных временных рядов в условиях ограниченной выборки: маски активности классов выделяются по кросс-корреляции сигнала с воздействием, а ковариация отобранных каналов проецируется на касательное пространство в точке риманова среднего, так что объект описывается отдельно с точки зрения каждого класса. Размерность признаков не зависит от объема выборки. На записях одного источника с восемью категориями воздействия метод превосходит нейросетевые модели, а исключение любой из компонент значимо снижает качество.
    \item Доказаны теоретические свойства касательных признаков ковариационных матриц. Инвариантность к невырожденному преобразованию каналов не меняет ответ логистической регрессии. Двусторонняя оценка искажения расстояний имеет неулучшаемую константу, выраженную через спектральный разброс касательных векторов. Оценка концентрации ошибки оценки ковариации в геодезической метрике не зависит от истинной ковариации.
    \item Предложена мультимодальная архитектура реконструкции воздействия по двум синхронно регистрируемым сигналам с контрастивным выравниванием совместных представлений с пространством предобученных эмбеддингов воздействия и двухстадийной диффузионной генерацией. Объединение модальностей повышает качество реконструкции по сравнению с каждой из них в отдельности, а априорная диффузионная модель необходима для семантической согласованности результата.
    \item Разработан метод восстановления отсутствующих каналов многоканального сигнала по геометрии расположения сенсоров и его вероятностное обобщение на основе маскированного согласования потоков. Доказано, что при точном векторном поле обобщение восстанавливает условное распределение пропусков. Метод применен к записям с неполным набором сенсоров.
\end{enumerate}

Теоретическая значимость результатов заключается в строгом обосновании широко применяемой конструкции касательных признаков: получены утверждения с явными константами, связывающими число каналов, длину ряда и ошибку признаков. Практическая значимость состоит в применимости методов к любым многоканальным сигналам высокой размерности и, в частности, в возможности декодирования по записям одного источника объемом в десятки объектов, в нейросетевой реконструкции воздействия по синхронным записям многих источников и в работе с записями с неполным набором каналов. Программные реализации методов опубликованы.

Результаты работы рекомендуется использовать при декодировании внешнего воздействия по многоканальным сигналам с малой размеченной выборкой, в частности по записям одного источника, когда объем выборки измеряется десятками объектов и нейросетевые модели неприменимы, для чего предназначены методы оценки лага и классификации, и при построении общих для многих источников нейросетевых моделей реконструкции по синхронным записям нескольких модальностей, в том числе с неполным набором каналов.

К перспективам дальнейшего развития темы относятся обобщение постановки на большее число модальностей с неизвестными взаимными лагами, включение вероятностного восстановления каналов в контур декодирования, а также перенос методов на мультимодальные временные ряды иной природы.
