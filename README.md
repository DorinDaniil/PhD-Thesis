## Structure

- `dissertation/` — текст диссертации (`main.tex`)

- `slides/` — слайды защиты (`main.tex`)
- `common/` — общие данные и настройки (`data.tex` — сведения об авторе и теме, `characteristic.tex` — общая характеристика работы, `concl.tex` — заключение)
